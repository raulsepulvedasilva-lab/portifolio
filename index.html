PROJETO 01 / RESIDENCIAL

Um refúgio de conforto.

Um conceito de climatização para uma sala de estar integrada, equilibrando o conforto térmico, a acústica e a estética do ambiente.

O desafio

Distribuir o ar de forma agradável sem direcionar o fluxo para as áreas de permanência e sem comprometer o projeto de interiores.

A solução

Dimensionamento conforme a carga térmica, escolha de equipamento inverter e instalação com tubulação organizada e acabamento discreto.

O foco

Operação silenciosa, acesso para manutenção e uso responsável de energia.

Projeto demonstrativo. A imagem ilustra o conceito, não uma execução real deste perfil.

PROJETO 02 / COMERCIAL

Desempenho em cada ambiente.

Um conceito de climatização para um ambiente corporativo com diferentes áreas de uso, rotinas e demandas de temperatura.

O desafio

Atender ambientes com ocupações variadas, mantendo o conforto durante a jornada de trabalho e a operação do espaço.

A solução

Planejamento de um sistema com controle por zonas, organização da área técnica e integração com uma rotina preventiva.

O foco

Desempenho consistente, facilidade de manutenção e eficiência operacional.

Projeto demonstrativo. A imagem ilustra o conceito, não uma execução real deste perfil.
